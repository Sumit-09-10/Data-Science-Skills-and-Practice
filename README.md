## About This Repository

This repository contains my **Data Science learning journey**, including practice notebooks, problem-solving exercises, data analysis work, visualization practice, and practical projects.

The repository is being built step-by-step as I progress toward becoming **placement-ready for Data Science, Machine Learning, Generative AI, and related roles**.

It focuses mainly on hands-on implementation rather than only theoretical learning.
